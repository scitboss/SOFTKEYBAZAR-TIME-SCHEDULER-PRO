## 🚀 About The Project

<img align="right" alt="Coding" width="350" src="https://cdn.dribbble.com/users/1162077/screenshots/3848914/programmer.gif"/>

**SOFTKEYBAZAR TIME SCHEDULER PRO** ek modern, lightweight Windows desktop application hai jo aapko apne computer ke **Shutdown**, **Restart**, **Sleep**, aur **RTC Wake Alarm** ko professionally schedule karne ki suvidha deta hai.

<br/>

### ✨ Key Highlights

- 🎨 **Premium Dark + Blue + Purple UI**
- ⚡ **Zero external dependencies**
- 🪶 **Ultra lightweight** (< 10 MB EXE)
- 🔒 **Safe & secure** — no file deletion
- 🕐 **Live digital clock** with countdown
- 🔔 **Smart notifications** (5 min, 1 min, 10 sec)
- 💾 **Auto-save** schedules to JSON
- 🔁 **Daily & weekly** recurring schedules
